# Game Dev OS – Product Roadmap

## Development Philosophy

Game Dev OS will be built incrementally.

Each phase must deliver real value before moving to the next.

We will never build features simply because they are interesting.

Every new feature should strengthen the core workflow.

---

# Version 0.1 – Foundation

Goal:
Create the technical foundation of the application.

Features:

- Next.js setup
- Tailwind CSS
- Folder architecture
- Design system
- Documentation
- Landing page
- Dashboard layout
- Git workflow

Status:
🟡 In Progress

---

# Version 0.2 – Authentication

Goal:
Allow developers to create accounts and securely access projects.

Features:

- Sign up
- Login
- Logout
- User profiles
- Team invitations

---

# Version 0.3 – Projects

Goal:
Create a central workspace for every game.

Features:

- Create projects
- Edit project information
- Project dashboard
- Team members
- Build versions

---

# Version 0.4 – Playtests

Goal:
Track every playtest in one place.

Features:

- Create playtest sessions
- Tester information
- Objectives
- Observations
- Feedback categories
- Attach screenshots

---

# Version 0.5 – Tasks & Bugs

Goal:
Turn feedback into actionable work.

Features:

- Kanban board
- Tasks
- Bugs
- Priorities
- Status tracking
- Assign developers

---

# Version 0.6 – Design Documentation

Goal:
Replace scattered design documents.

Features:

- Game Design Document (GDD)
- Level Design Document (LDD)
- System Design
- Character Design
- Mechanics
- Version history

---

# Version 0.7 – Production

Goal:
Help teams manage development.

Features:

- Milestones
- Sprint planning
- Build history
- Roadmaps
- Risk tracking

---

# Version 0.8 – Business

Goal:
Support the business side of indie development.

Features:

- Budget planning
- Expense tracking
- Publisher CRM
- Funding tracker
- Pitch deck workspace

---

# Version 0.9 – AI Workspace

Goal:
Speed up development using AI.

Features:

- AI playtest summaries
- AI bug summaries
- AI design assistant
- AI sprint planning
- AI document writing

AI should assist developers, never replace them.

---

# Version 1.0 – Game Dev OS

Goal:
Deliver the first complete public release.

Features:

- Stable platform
- Team collaboration
- Connected workflows
- Documentation
- Playtesting
- Tasks
- Bugs
- Milestones
- AI Assistant

Version 1.0 represents the first complete operating system for indie game development.

---

# Future Vision

Beyond Version 1.0, Game Dev OS may expand into:

- Community Hub
- Portfolio hosting
- Team finder
- Asset management
- Publisher marketplace
- Steam integration
- Discord integration
- Analytics
- Cloud build tracking

These features will only be built if they strengthen the core mission.
